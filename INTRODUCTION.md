Check npm and GitHub plugin bundles for updates without leaving DSH. Review the exact target and confirm before an update starts.

**Command Usage**: Use `/plugin-updater check` to check installed bundles, or `/plugin-updater update foo` to prepare an update. Use `/plugin-updater help` for all commands. The `plugin_updates` tool lets an agent check without installing anything.

An update removes the old package before installing the new one. If installation fails, recovery is manual.
